# Childhood Maltreatment and Brain Centiles

This repository contains the analysis code for the study **"Childhood Maltreatment and Brain Centiles"**.

**Contact:** Johannes Julius Mohn (johannes.j.mohn@maxplanckschools.de)

## Reproducibility

R package dependencies are managed using `renv`. The project environment can be restored with:

```r
renv::restore()
```

## Data availability

The study data are not publicly available due to participant privacy and data protection requirements.
