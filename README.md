# Childhood Maltreatment and Brain Centiles

This repository contains the analysis code for the study **"Maltreatment Predicts Centiles of Individual Variation from Normative Brain Growth in Children"**.

**Contact:** Johannes Julius Mohn ([johannes.j.mohn@maxplanckschools.de](mailto:johannes.j.mohn@maxplanckschools.de))

## Reproducibility

The analyses were conducted in R. Package dependencies are managed using [`renv`](https://rstudio.github.io/renv/).

After cloning or downloading the repository, open the R project and restore the project environment with:

```r
renv::restore()
```

## Data availability

The data used in this study are available upon reasonable request to the corresponding author of the study.
